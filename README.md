# PHARAOH

## Overview

Project PHARAOH is a city-builder game set in Ancient Egypt. The project is inspired by classic titles such as *Pharaoh* (😉), "Zeus", and the *Anno* series, focusing on deep economic simulation, logistics, and city development systems.

The game is currently in early development and serves as a working prototype of core simulation systems.

---

## Current State

The project is in an early prototype stage. Core gameplay systems are actively being developed and iterated upon.

---

## Implemented Systems

### Citizen AI
- Basic simulation of citizens within the city
- Task-based behavior system
- Movement and interaction with world objects

### Goods Flow System
- Management of resource distribution between buildings
- Simulation of supply and demand chains
- Foundation for economic balancing

### Construction System
- Placement and construction of buildings
- Building destruction mechanics
- Grid-based city expansion logic

### Simulation Core
- Core city simulation loop
- Integration of AI, logistics, and construction systems

---

## Technology Stack

- Engine: Unity
- Concurrency: Unity Job System

---

## Design Direction

The project focuses on:
- Emergent city simulation
- Resource-driven economy
- Systemic interaction between citizens, buildings, and logistics
- Expansion of gameplay depth through interconnected systems

---

## Status

This is a work-in-progress prototype. Features, mechanics, and systems are subject to change as development progresses.
